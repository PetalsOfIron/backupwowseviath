# backupwowseviath

Backup of everything needed to rebuild the SeviathsUsefulTools workflow.

- `README-FOR-CLAUDE.md`: read this first. It describes the project, the repos, the scripts, the rules and how to rebuild everything on a new PC.
- `pc-scripts/`: the scripts that live on the PC outside the addon folder (the data watcher, the Startup launcher, the desktop launchers).
- The addon code is in https://github.com/PetalsOfIron/WOWSeviathsUsefultools-Retail and the collected data in https://github.com/PetalsOfIron/Data-wow.
- `saved/` (the player's saved game data) is NOT in this repo while it is public: it holds character names, gold history and settings. It is pushed here only when the repo is private.
